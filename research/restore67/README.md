# RESTORE67
Opt-in evaluator sign transport fault injection before actual MCTS backup, with exact mask-domain implementation of syndrome decoding and independent received-codeword verification. Explicit auxiliary complex three-qubit X-error code, coherent and common-mode failures, actual previously recorded R65 states. Separate g3 high-budget and actual pinned Rapfi benchmarks; 9x9 fallback without NNUE, 15x15 actual NNUE on distinct center-embedded boards. Raw paths and plots in incremental snapshot. No physical hardware, arbitrary QEC or production strength admission. See docs/RESTORE67_RESULTS.md.
